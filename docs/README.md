## 置き場所の決め方

- **仕様**（作る対象が何か、どう振る舞うべきか）→ `spec/` と `stages/`。実装より先に書く。
- **決定**（複数の選択肢から一つを選び、後から理由を問われるもの）→ `adr/`。1 決定 1 ファイル、
  後から書き換えず、覆すときは新しい ADR を足して古いものを `Superseded` にする。
- **授業で配られた情報・講義メモ・提出要件**→ `notes/`。自分の設計ではなく外から来たもの。
- **コードを読めば分かること**→ どこにも書かない。コード内のコメントにする。

コード中のコメントに「docs/… 参照」と書かない。ファイルは動くし消える。コメントはそれ自体で
意味が通るように書く。恒久的な記録（ADR）だけは引用してよい。
