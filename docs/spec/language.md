# MPPL の仕様

MPPL (Mini Pascal-like Programming Language) は Pascal の部分集合。このコンパイラは MPPL を
読んで CASL II（COMET II 仮想機械のアセンブラ）を出す。

> **この文書の出所。** 以下は標準的な MPPL 定義の整理であって、授業の課題文そのものではない。
> 課題文と食い違ったら**課題文が正**。照合して直すこと。照合すべき箇所には «要確認» を付けた。
> 課題文の写しは [../notes/](../notes/) に置く。

## 字句

ソースは、**分離子で区切られたトークンの列**として読む。トークンは全部で **49 種類** «要確認»
— 予約語 28 + 名前 + 符号なし整数 + 文字列 + 記号 18。

### 分離子

トークンを区切るもので、それ自身はトークンにならない。

| 種類   | 綴り                                        |
| ------ | ------------------------------------------- |
| 空白   | 空白文字 (` `)、水平タブ (`\t`)             |
| 改行   | `\n`、`\r`、`\r\n` «要確認: 3 通りの扱い»   |
| 注釈   | `{ ... }` または `/* ... */`                |

注釈は**入れ子にしない**。`{` を見たら次の `}` までが注釈。`{ { }` は最初の `}` で閉じる。
2 つの形式が混ざっても互いを終端しない（`{ /* }` は `}` で閉じる）。

分離子はいくつ連続してもよく、0 個でもよい場所がある（`a:=1` は分離子なしで 3 トークン）。
ただし**分離子が必須な場所がある**: `x div y` の `div` は予約語なので `xdivy` と書くと 1 つの
名前になる。トークンの切り出し規則（最長一致）がこれを自動的に処理する。

### 名前 (識別子)

```
名前 = 英字 { 英字 | 数字 }
英字 = "a".."z" | "A".."Z"
数字 = "0".."9"
```

- 数字から始められない。`_` は英字に含まれない «要確認»。
- 大文字と小文字は**区別する** «要確認»。`X` と `x` は別の名前。
- 予約語と完全に一致する綴りは予約語として扱い、名前にはならない。予約語は小文字のみなので
  `Begin` は名前になる（区別する場合）。
- 長さの上限 «要確認: 課題文に上限があるか。なければ動的に伸ばす»。

### 符号なし整数

```
符号なし整数 = 数字 { 数字 }
```

- 符号は含まない。`-5` は「`-` と `5`」の 2 トークンで、負数は構文（単純式の符号）で作る。
- 値の範囲は **0 〜 32767** «要確認»。CASL II の 1 語が 16 bit 符号付きなので上限がこれになる。
  `32768` は字句としては切り出せるが値が範囲外 → **エラーにする**（段階1 で検出するか段階3 か
  は要確認だが、字句解析器が値に変換する時点で気付ける）。
- 先行ゼロ `007` の扱い «要確認: 通常は 7 として許す»。

### 文字列

```
文字列 = "'" { 文字 | "''" } "'"
```

- `'` で囲む。中に `'` を 1 つ書きたいときは `''` と 2 つ重ねる（これで 1 文字）。
- **改行を含められない**。閉じる `'` が同じ行に無ければエラー。
- 字句解析器が持つ値は、`''` を `'` に戻した**中身**。`'don''t'` の長さは 5。
- 長さ 1 の文字列は文字定数（`char` 型の定数）として使える。長さ 0 (`''`) や 2 以上の文字列は
  出力文の中でしか書けない。この区別は**構文と意味の話**なので、字句解析器は長さを区別せず
  すべて「文字列」トークンとして返す。

### 記号 (18 種類)

| 綴り | 用途                     | 綴り | 用途                     |
| ---- | ------------------------ | ---- | ------------------------ |
| `+`  | 加算 / 単項プラス        | `(`  | 括弧開き                 |
| `-`  | 減算 / 単項マイナス      | `)`  | 括弧閉じ                 |
| `*`  | 乗算                     | `[`  | 添字開き                 |
| `=`  | 等しい                   | `]`  | 添字閉じ                 |
| `<>` | 等しくない               | `:=` | 代入                     |
| `<`  | より小さい               | `.`  | プログラムの終わり       |
| `<=` | 以下                     | `,`  | 並びの区切り             |
| `>`  | より大きい               | `:`  | 型の区切り / 出力の桁数  |
| `>=` | 以上                     | `;`  | 文・宣言の区切り         |

**最長一致で切る。** これを外すとほぼ全部壊れる:

| 入力 | 正しい切り方   | 間違えると          |
| ---- | -------------- | ------------------- |
| `<=` | `<=` 1 個      | `<` `=` の 2 個     |
| `<>` | `<>` 1 個      | `<` `>` の 2 個     |
| `>=` | `>=` 1 個      | `>` `=` の 2 個     |
| `:=` | `:=` 1 個      | `:` `=` の 2 個     |
| `:`  | `:` 1 個       | —（次が `=` でなければ `:`） |

つまり `<` `>` `:` を読んだら**次の 1 文字を覗いて**から決める。覗いた文字が使えなければ
戻す（先読み 1 文字）。

MPPL に無い記号: `/`（除算は `div`）、`{` `}`（注釈）、`!` `&` `|` `%` `^` `~` `"` `@` `#` `$`
`?` `\` `_`。これらが出てきたら字句エラー。

### 予約語 (28 語)

すべて小文字。

| | | | |
| --- | --- | --- | --- |
| `and` | `array` | `begin` | `boolean` |
| `break` | `call` | `char` | `div` |
| `do` | `else` | `end` | `false` |
| `if` | `integer` | `not` | `of` |
| `or` | `procedure` | `program` | `read` |
| `readln` | `return` | `then` | `true` |
| `var` | `while` | `write` | `writeln` |

`readln` と `read`、`writeln` と `write` は別の予約語。最長一致で切るので `readln` は
`read` + `ln` にならない（名前の切り出しが最長一致なら自動的にそうなる）。

### 字句エラー

| 何が起きたか                       | 例            |
| ---------------------------------- | ------------- |
| MPPL に無い文字                    | `a @ b`       |
| 閉じていない文字列                 | `'abc`        |
| 文字列の中に改行                   | `'ab` + 改行  |
| 閉じていない注釈（ファイル末尾まで）| `{ abc`     |
| 整数が範囲外                       | `40000`       |

どれも**行番号を添えて報告し、読み飛ばさない** «要確認: 課題文が求める報告形式»。
