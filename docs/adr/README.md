# 設計決定の記録 (ADR)

後から「なぜこうなっているのか」を問われる決定を 1 ファイル 1 件で残す。コードを読めば分かる
こと（何をしているか）は書かない。書くのは**選ばなかった道と、選んだ理由**。

## 書くべき決定の目安

- 選択肢が複数あり、どれでも動いた（再帰下降 vs 演算子優先順位法、など）
- 後から変えると広く波及する（AST の所有権、エラー報告の方針、目標機械）
- 授業の指定ではなく自分で決めた

逆に、授業で指定されたことは決定ではない。[../notes/](../notes/) に写す。

## 手順

1. `template.md` を `NNNN-短い題.md` にコピーする（番号は連番、埋め直さない）。
2. 埋めてコミットする。
3. 後から覆すときは**書き換えず**、新しい ADR を足して古い方の状態を
   `Superseded by NNNN` にする。決定した時点の判断が残ることに意味がある。
