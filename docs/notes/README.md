# 授業メモ

外から来た情報を写す場所。自分の設計判断は書かない（それは [../adr/](../adr/)、仕様は
[../spec/](../spec/) と [../stages/](../stages/)）。

置くもの:

- 課題文・提出要件（締切、提出形式、評価観点）
- 講義で説明された方式や制約
- 参考文献、参照した資料の場所

ファイル名は `YYYY-MM-DD-内容.md`（回ごとのメモ）か `assignment-N.md`（課題文）。

配布資料の PDF などをそのまま置きたい場合は、リポジトリに入れてよいか（再配布の可否）を確かめ
てから。判断がつかないなら、出所と該当箇所だけをメモに書いて本体は置かない。
